- **Domain Architecture**: Refactored `BaseDocument` and `BaseLineItem` abstract inheritance models in `sales/models/`.
- **Documentation Suite**: `architecture.md`, `design-system.md`, `coding-standards.md`, `roadmap.md`, `changelog.md`.
