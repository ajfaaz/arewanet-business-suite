# 03. Design System Guide - ABS v1.0

## Tokens
- `--abs-primary`: `#0B5ED7`
- `--abs-success`: `#198754`
- `--abs-danger`: `#DC3545`
- `--abs-dark`: `#1E293B`

## Standard Components
- `.abs-card`: Rounded cards with `16px` border radius and box-shadow elevation.
- `.abs-btn`: Custom button classes with hover states and icons.
- `.abs-table`: Responsive data tables with sticky headers and zebra striping.
